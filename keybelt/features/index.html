Features

Everything in the Free edition

Tools for your curves and an interface that sits where you already work. Every card links to its documentation page.

Tools

Keys Editor

Slider-based key effects on the keys you have selected: smooth, push / pull, interpolate, ease, wave, offset, hierarchy offset and more, plus key cleanup (delete flat or redundant keys) and bake. Drag a slider and the effect applies live; double-click to reset.

Docs

Baker

Bake animation in world space, in an object space or relative to a camera, with a list of baked controls you can reuse.

Docs

Offseter

Offsets the animation based on the transform you give the selected object. Move the object, and the whole animation follows.

Docs

Reset All

Reset every keyable channel of the selection to its default in one click. One undo step, locked channels are skipped.

Docs

Selector

An always-on glass HUD for selection sets. Colour chips select, colour dots filter.

Docs

Motion Trail Beta

Viewport motion trails, world or camera relative, with editable handles. In beta: features may change.

Docs
Interface

Timeline toolbar

Keys Editor sliders and action buttons right under the timeline. Reorder and hide tools in Settings.

Docs

Graph Editor toolbar

The same sliders and action buttons attached to the Graph Editor. It never forces the editor to stay wide.

Docs

Radial menu

A floating wheel on Alt+Q. One wheel over the viewport, another over the Graph Editor. Configure both in Settings.

Docs

Viewport bar

A floating bar with your favourite tools in the viewport. It stays visible while Maya is in the background.

Docs

Time Dragger HUD

Hold the key and drag for an endless scrub with a temporary timeline showing range, keys and bookmarks. Shift = fine, Ctrl = coarse.

Docs

Settings

Toolbars, hotkeys, radial menu and viewport bar contents, startup and updates in one window.

Docs
