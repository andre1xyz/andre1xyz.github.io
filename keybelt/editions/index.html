Editions and roadmap

One edition now, a second one planned

Today there is one edition, Free, and it is in public beta. It is free to use, but it is not open source and it only holds the core tools. A Pro edition with more tools is planned.

Available now

Free (beta)

Free to use for personal and commercial work. Not open source. The core KeyBelt tools, as a public beta.

  • Keys Editor, Baker, Offseter, Reset All, Selector
  • Motion Trail
  • Radial menu, timeline and Graph Editor toolbars, viewport bar
  • Time Dragger HUD
  • Settings and an update check
Download the beta
Planned

Pro

More advanced tools for production animation work. It does not exist yet. The tools listed below are what it would be built from.

  • Everything in Free
  • Tools for secondary motion, temporary rigs and poses

Planned means planned. Nothing here is promised, no price or date is decided, and what lands in which edition can change.

Upcoming tools

What I am working on

34 tools exist in my private toolset. None of them is in KeyBelt today, and they are planned for Pro.

Key tools 2

  • Key Blender

    Blend or hold world-space translate and rotate across a frame range.

  • Linker

    Store an offset, snap now, or match a range between objects, without constraints.

Baking and curve tools 3

  • Attribute Switcher

    Switch the attributes of the selected object while keeping the original animation.

  • Rotation Order

    Change the rotation order and keep the original animation.

  • Path Master

    Create a path from a control, adapt it, then bake.

Temporal tools 5

  • Temporal IK

    A temporary IK chain on top of existing animation.

  • Temporal FK

    A temporary FK control chain with hierarchy detection, bake and cleanup.

  • Temporal Pivot

    A temporary pivot for animation without changing the original pivot.

  • Edit Pivot

    A temporary median or last-selected pivot you can move while the originals stay untouched.

  • Temp Spline IK

    A temporary spline IK setup for ropes, tails and chains, baked back to the originals.

One-shot utilities 2

  • XForm Transfer

    Copy world translate and rotate from one object and paste onto others.

  • Rotation Normalizer

    Select an object and normalise crazy rotation values.

Pose tools 3

  • Copy Pose

    Copy and paste poses between the same rig or different rigs.

  • Clean Up

    Clamp keys to the playback range: bookend keys added, keys outside deleted.

  • Pose Library

    Save and apply poses and selection sets with thumbnails. Compatible with existing pose-library files.

Animation assist 1

  • Animation Assistant

    Live auto-pose, stickman pose drawing and AI-assisted helpers for blocking.

Secondary motion 4

  • Overlap Tool

    Overlaps for individual controls, fast and without pre-baking.

  • Chain Lag

    World-space lag on a control chain that follows the root's motion path.

  • Dynamic Curve Rig

    Dynamic curve overlap rigs built on nHair, with sim bake and cleanup.

  • Velocity Annotation

    Viewport annotations showing how fast your controls move, in your choice of units.

Rigging 2

  • Advanced Rigging

    An auto-rig wizard: place guide points on the mesh, then build skeleton, FK/IK controls and weights.

  • Mesh Pick

    Control-less posing: hover a mesh part, click and drag.

Utility and export 7

  • Playblast Manager

    Playblasts with custom viewport settings, folders, thumbnails and metadata.

  • Animation Exporter

    Export animation curves to versioned JSON files and import them back.

  • Geometry Instancer

    Create instanced copies of geometry with the shading preserved.

  • Skin Rigid Preview

    Split a skinned mesh into one piece per bone for a light preview, with optional face LOD.

  • Drawing Painter

    A viewport stroke tool: draw a line and lay poses or shapes along it.

  • Shape Grab

    Soft-sculpt on a live copy of a skinned mesh.

  • Make Daily

    Create daily renders and manage the dailies workflow for Maya projects.

Management and viewers 4

  • Character Viewer

    View and manage the characters in your scene.

  • Channel Panel

    A compact channel box with display and animation layers, made for animators.

  • Panel Selection

    A picker panel with selection buttons over a photo or schematic of the character.

  • Scripts Per Project

    Build and update per-project shelves while keeping your own buttons.

System 1

  • DG / Parallel

    Switch Maya's evaluation between DG and Parallel in one click.
